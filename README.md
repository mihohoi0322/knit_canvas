# Knit Canvas

Knit Canvas は、セーターなどのカラーワーク（編み込み模様）を方眼上で設計するためのブラウザアプリです。実際の編みゲージに合わせて目数・段数を設定し、マウス、タッチ、Apple Pencilで1目ずつ色を配置できます。

## 主な機能

- 1〜200目・段の方眼サイズ設定
- 10cmあたりの目数・段数による完成寸法の計算
- 現行100色の色見本
- 色番号検索と最近使った5色の表示
- 鉛筆、消しゴム、Undo、Redo
- 3回・5回・8回のパターンリピート表示
- 横1段ごとの使用色数確認
- ブラウザ内への自動保存
- `.knitcanvas`形式での保存・読み込み
- A4 PDFの書き出しと印刷
- PC、タブレット、スマートフォン向けレスポンシブ表示

画面上の色は色見本画像から取得した近似色です。実際の毛糸は色番号と実物の見本で確認してください。

## 必要な環境

- Node.js 20.19以上、または22.12以上
- npm

## セットアップ

```bash
npm install
npm run dev
```

起動後、ターミナルに表示されたローカルURLをブラウザで開きます。

## コマンド

```bash
# 開発サーバー
npm run dev

# 単体・コンポーネントテスト
npm test -- --run

# Playwrightによる動作テスト
npm run test:e2e

# 型チェック
npm run typecheck

# Lint
npm run lint

# 本番ビルド
npm run build
```

Playwrightの動作テストではChromiumとWebKitを使用し、次の操作を確認します。

- 目数・段数の初期値と変更反映
- 選択色の方眼への描画と最近使った色への反映
- PDFの生成とダウンロード
- 一般的なPC画面サイズへのレイアウト追従

## データについて

作品はブラウザのIndexedDBへ自動保存されます。別環境への移動やバックアップには「プロジェクト保存」で生成される `.knitcanvas` ファイルを使用してください。

旧パレットを含む作品を読み込んだ場合、パレットは現行100色へ置き換えられます。現行の色番号に対応しない旧色のセルは未着色になります。
